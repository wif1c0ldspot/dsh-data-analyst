These documents describe the current implementation only. Superseded plans and
abandoned proposals are not maintained here as competing instructions in the
working tree, and are not preserved in this repository's public history either —
it is a single clean export, not a development log. Measured evidence and release
gates are tracked internally rather than in this distribution; this repository
states which capabilities are proven and which are open.
